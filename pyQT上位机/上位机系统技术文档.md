# 基于视觉与GPS的等离子智能巡航无人船

## 📋 项目概述

### 项目背景
本项目是一个基于等离子体推进技术的智能水质监测系统上位机，主要用于河道水质实时监测、水下机器人控制和数据可视化分析。系统集成了多种传感器，实现了从数据采集到可视化显示的完整监测流程。

### 系统特点
- 🚀 **等离子体推进技术**：创新性的水下推进方案
- 📊 **多传感器融合**：集成TDS、温度、距离、GPS、IMU等多种传感器
- 🎯 **实时监测**：毫秒级数据采集和显示
- 🗺️ **智能导航**：GPS自动巡航功能
- 📈 **可视化分析**：多种图表显示模式
- 🔧 **模块化设计**：易于扩展和维护
