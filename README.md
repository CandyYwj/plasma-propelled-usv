# 智水监测者：基于等离子推进的河道智慧监测系统

## 项目简介

本项目面向河道水文与水质监测，目录包含 STM32 船载控制程序、串口可视化上位机、传感器独立调试工程、船体模型和项目方案。项目方案提出电机与等离子体双模态推进，以及结合视觉的自主避障；现有主控源码可核对到的是传感器采集、电机 PWM、姿态控制和 GPS 目标导航等逻辑，不能仅凭这些源码确认等离子体推进切换和视觉避障已完成联调。

## 项目信息与成果

- 成功通过等离子体驱动小船在湖中完成水质采样。

## 系统架构与硬件组成

船载工程的目标器件为 **STM32F429ZGTx**，基于 STM32 HAL。教程和源码对应的接口包括：UART1 超声波、UART2 激光、USART6 GPS、UART8 上位机、UART3 调试；DS18B20 单总线温度、ADC 采集 TDS、软件 I²C 读取 IMU，以及 TIM1 两路 PWM 电机控制。上位机通过串口接收数据并显示曲线与轨迹。方案还列有 HC-14 无线模块、OpenMV 和等离子体推进装置，具体硬件装配与源码版本的对应关系需要核实。

## 主要功能

- 读取水温和 TDS，按温度补偿计算 TDS；采集激光、超声波距离并进行中值滤波。
- 接收 GPS 数据，读取 IMU 姿态；提供航向 PID、GPS 目标距离和方位角计算以及电机 PWM 控制逻辑。
- 通过串口解析测量、运动和导航命令，发送传感器文本数据。
- 上位机选择串口、启动或停止测量，显示距离、温度、TDS 曲线和 GPS 轨迹，并提供控制界面。当前上位机和主控部分控制命令格式不一致，见注意事项。

## 开发、编译与运行

1. 使用 Keil MDK 打开 `STM32F4小船代码/Projects/MDK-ARM/stm32f429.uvprojx`，选择 `Template` 目标。工程记录的编译器为 ARM Compiler 5.06 update 7，目标为 STM32F429ZGTx，并启用了 HEX 输出；按本机安装情况配置器件支持包、编译器和调试器后构建。
2. 按实际开发板和调试器连接方式在 Keil 配置下载，烧录生成的程序并复位。具体探针、接线和供电以实际硬件为准；本次未编译、烧录或连接设备。
3. 激光和超声波目录下各有 `Projects/MDK-ARM/stm32f103.uvprojx` 独立工程，目标为 STM32F103C8，应根据实际测试板分别打开，不要当作船载主工程。
4. 上位机技术文档列出 Python 3.8+，依赖 PySide6、pyserial、NumPy、Matplotlib；依赖版本未锁定，需选用相互兼容的版本。进入 `pyQT上位机/` 后执行：

   ```text
   pip install PySide6 pyserial numpy matplotlib
   python serial_monitor_gui.py
   ```

5. 连接实际串口，在界面选择端口和波特率；上位机默认 115200。主控支持 `begin`、`end`，以及 `nav_target:纬度,经度`、`nav_start`、`nav_stop`、`nav_status` 等文本指令。联调前应核对双方格式和设备接线。

## 关键模块

- `STM32F4小船代码/Users/main.c`：初始化、命令解析、传感器上报和控制主循环。
- `STM32F4小船代码/Drivers/BSP/ds18b20/ds18b20.c`、`tds/tds.c`：水温读取、TDS 采集与温度补偿。
- `STM32F4小船代码/Drivers/BSP/ultrasonic/ultrasonic.c`、`laser/laser.c`、`filtering/filtering.c`：测距解析与中值滤波。
- `STM32F4小船代码/Drivers/BSP/iic/IOI2C.c`、`IMU/IMU.c`、`GPS/gps.c`：软件 I²C、姿态数据和 GPS 解析。
- `STM32F4小船代码/Drivers/BSP/TIM/tim.c`、`pid/pid.c`、`navigation/navigation.c`：PWM、姿态控制、距离与方位角计算。
- `STM32F4小船代码/Drivers/BSP/uart1/`、`uart2/`、`uart3/`、`uart6/`、`uart8/`：各路串口接收与发送。
- `pyQT上位机/serial_monitor_gui.py`：串口线程、数据解析、控制界面和图表。

## 注意事项

- 上位机方向按钮发送单字节命令，主控当前解析 `advance`、`left`、`right`、`stop` 文本；上位机导航发送 `NAV:经度,纬度`，主控则使用 `nav_target:纬度,经度` 后再发送 `nav_start`。两端不能直接按这两套格式假定兼容，需要先统一协议并实机验证。
- DS18B20 读取包含约 760 ms 的阻塞等待，连续测量还包含延时；主循环中标称的控制周期不等于实测实时性，需结合设备验证。
- 教程、技术文档和方案中的功能描述、性能数据及测试勾选并不等同于本次验证结果；设备型号、接线、实际功能、精度和运行表现需作者补充确认。TDS 参数需要结合传感器和标准液校准。
- `教程练习/` 是学习示例，第三方资料和已有编译产物不代表当前工程已通过构建。推进装置及电机调试前，应依据实际硬件确认供电、驱动和安全操作条件。
