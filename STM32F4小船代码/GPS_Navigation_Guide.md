# GPS导航控制使用指南

## 概述
本系统实现了基于GPS坐标的自动导航功能，可以让船只自动航行到指定的经纬度坐标。

## 功能特性
- **GPS坐标导航**：基于经纬度坐标的精确导航
- **自动航向计算**：自动计算到目标点的最佳航向
- **距离监控**：实时监控到目标的距离
- **到达检测**：自动检测是否到达目标点
- **速度控制**：根据距离自动调整航行速度

## 控制命令

### 1. 设置导航目标
```
nav_target:纬度,经度
```
例如：
```
nav_target:39.9042,116.4074    // 北京天安门
nav_target:31.2304,121.4737    // 上海外滩
nav_target:22.3193,114.1694    // 香港维多利亚港
```

### 2. 开始GPS导航
```
nav_start
```
- 开始自动导航到设定的目标点
- 系统会自动计算航向并控制船只航行
- 需要先设置有效的导航目标

### 3. 停止GPS导航
```
nav_stop
```
- 停止GPS导航
- 停止所有电机
- 返回手动控制模式

### 4. 查询导航状态
```
nav_status
```
返回导航状态信息：
- 导航是否激活
- 是否到达目标
- 到目标的距离
- 目标方位角

## 导航参数

### 默认参数
- **到达阈值**：5米（距离目标5米内认为到达）
- **减速阈值**：20米（距离目标20米内开始减速）
- **最大速度**：40% PWM
- **最小速度**：15% PWM
- **基础速度**：25% PWM

### 航向控制
- **控制增益**：0.5（航向误差到PWM的转换系数）
- **控制频率**：50Hz（每20ms更新一次）

## 工作原理

### 1. 坐标转换
```c
// GPS坐标处理
double current_lat = Convert_to_degrees(Save_Data.latitude);
double current_lon = Convert_to_degrees(Save_Data.longitude);

// 处理半球标识
if (Save_Data.N_S[0] == 'S') current_lat = -current_lat;  // 南半球
if (Save_Data.E_W[0] == 'W') current_lon = -current_lon;  // 西半球
```

### 2. 距离计算
使用Haversine公式计算两点间的球面距离：
```c
float distance = Calculate_Distance(lat1, lon1, lat2, lon2);
```

### 3. 方位角计算
计算从当前位置到目标点的方位角：
```c
float bearing = Calculate_Bearing(lat1, lon1, lat2, lon2);
```

### 4. 航向控制
```c
// 计算航向误差
float yaw_error = target_bearing - current_yaw;

// 处理角度连续性
if (yaw_error > 180.0f) yaw_error -= 360.0f;
if (yaw_error < -180.0f) yaw_error += 360.0f;

// 差速控制
float left_pwm = base_pwm + yaw_error * gain;
float right_pwm = base_pwm - yaw_error * gain;
```

## 使用步骤

### 1. 基本导航流程
```
1. 确保GPS信号良好
2. 发送 "nav_target:纬度,经度" 设置目标
3. 发送 "nav_start" 开始导航
4. 观察船只自动航行到目标点
5. 到达目标后自动停止
6. 发送 "nav_stop" 停止导航（可选）
```

### 2. 导航监控
```
1. 发送 "nav_status" 查询导航状态
2. 观察实时数据反馈
3. 监控距离和方位角变化
```

## 数据反馈

### 导航状态信息
```
NAV_STATUS:ON,距离,方位角
```
例如：
```
NAV_STATUS:ON,25.3m,45.2°
```

### GPS坐标信息
```
GPS_LAT=纬度
GPS_LON=经度
```

## 注意事项

### 1. GPS信号要求
- 确保GPS模块有良好的卫星信号
- 在开阔水域使用效果最佳
- 避免在建筑物或桥梁下使用

### 2. 坐标精度
- 使用6位小数精度的坐标
- 确保坐标格式正确（纬度在前，经度在后）
- 注意半球标识（N/S, E/W）

### 3. 环境因素
- 水流会影响实际航行轨迹
- 风力可能导致航向偏差
- 建议在相对平静的水域使用

### 4. 安全考虑
- 首次使用建议在安全环境中测试
- 设置合理的到达阈值
- 准备紧急停止命令

## 故障排除

### 1. 导航不启动
- 检查GPS信号是否良好
- 确认目标坐标格式正确
- 检查是否设置了有效的目标点

### 2. 航向偏差大
- 检查IMU传感器是否正常
- 调整航向控制增益
- 检查电机响应是否正常

### 3. 无法到达目标
- 检查到达阈值设置
- 确认GPS坐标精度
- 检查是否有环境干扰

### 4. 速度异常
- 检查PWM输出是否正常
- 调整速度控制参数
- 检查电机连接

## 高级功能

### 1. 多航点导航
可以扩展为支持多个航点的路径导航：
```
nav_waypoint:lat1,lon1,lat2,lon2,lat3,lon3
```

### 2. 路径规划
结合障碍物检测实现智能路径规划：
- 避障算法
- 最优路径计算
- 动态路径调整

### 3. 速度优化
根据环境条件自动调整航行速度：
- 根据水流速度调整
- 根据距离动态调整
- 根据电池电量调整
