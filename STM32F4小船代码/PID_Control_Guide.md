# PID控制使用指南

## 概述
本系统实现了基于IMU数据的PID姿态控制，主要用于智能水质监测船的航向控制。

## 功能特性
- **偏航角控制**：基于IMU的Yaw角数据进行航向控制
- **实时PID调节**：支持运行时调整PID参数
- **多控制模式**：支持手动控制和PID自动控制
- **数据反馈**：实时反馈控制状态和参数

## 控制命令

### 1. 启用PID控制
```
pid_on
```
- 启用PID控制模式
- 默认启用偏航角控制
- 设置基础前进PWM为20%

### 2. 禁用PID控制
```
pid_off
```
- 禁用PID控制模式
- 停止所有电机
- 返回手动控制模式

### 3. 设置目标偏航角
```
target_yaw:角度值
```
例如：
```
target_yaw:90.0    // 设置目标航向为90度
target_yaw:-45.0   // 设置目标航向为-45度
target_yaw:0.0     // 设置目标航向为0度
```

### 4. 调整PID参数
```
pid_gains:Kp:Ki:Kd
```
例如：
```
pid_gains:2.0:0.1:0.5    // 设置Kp=2.0, Ki=0.1, Kd=0.5
pid_gains:1.5:0.05:0.3   // 设置Kp=1.5, Ki=0.05, Kd=0.3
```

## 默认PID参数
- **偏航控制**：Kp=2.0, Ki=0.1, Kd=0.5
- **俯仰控制**：Kp=1.0, Ki=0.05, Kd=0.2
- **横滚控制**：Kp=1.0, Ki=0.05, Kd=0.2

## 控制原理

### 1. 角度处理
- 所有角度标准化到[-180°, 180°]范围
- 自动处理角度连续性（如从179°到-179°）

### 2. PID控制
- **比例项(P)**：响应当前误差，提供主要控制力
- **积分项(I)**：消除稳态误差，累积误差补偿
- **微分项(D)**：预测误差变化趋势，提供阻尼作用

### 3. 运动学映射
- 通道1控制左电机
- 通道2控制右电机
- 基础前进PWM：20%
- 转向控制：PID输出直接映射到左右电机差速

## 使用步骤

### 1. 基本航向控制
```
1. 发送 "pid_on" 启用PID控制
2. 发送 "target_yaw:目标角度" 设置目标航向
3. 观察船只自动调整到目标航向
4. 发送 "pid_off" 停止PID控制
```

### 2. 参数调优
```
1. 启用PID控制
2. 设置目标角度
3. 观察控制效果
4. 如果响应过慢：增加Kp
5. 如果有振荡：减少Kp，增加Kd
6. 如果有稳态误差：增加Ki
7. 使用 "pid_gains:Kp:Ki:Kd" 调整参数
```

## 数据反馈

### PID状态信息
```
PID_STATUS:ON,目标角度
```

### IMU角度数据
```
IMU_ANGLE:Roll,Pitch,Yaw
```

## 注意事项

1. **安全第一**：首次使用时建议在安全环境中测试
2. **参数调优**：PID参数需要根据实际船只特性调整
3. **环境因素**：水流、风力等环境因素会影响控制效果
4. **电池电量**：低电量可能影响电机响应
5. **传感器校准**：确保IMU传感器已正确校准

## 故障排除

### 1. 船只不响应
- 检查PID控制是否启用
- 检查电机连接
- 检查PWM输出

### 2. 控制不稳定
- 减少Kp参数
- 增加Kd参数
- 检查IMU数据是否正常

### 3. 响应过慢
- 增加Kp参数
- 检查电机功率是否足够
- 检查船只负载

### 4. 稳态误差
- 增加Ki参数
- 检查传感器精度
- 检查机械摩擦

## 高级功能

### 1. 多轴控制
当前系统主要实现偏航控制，可以扩展：
- 俯仰控制：前后平衡
- 横滚控制：左右平衡

### 2. 自适应控制
可以基于环境条件自动调整PID参数：
- 根据水流速度调整控制强度
- 根据负载重量调整基础PWM

### 3. 路径规划
结合GPS数据实现：
- 航点导航
- 路径跟踪
- 自动避障
