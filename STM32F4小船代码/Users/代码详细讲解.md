# 智能小船主控代码详细讲解（main.c）

## 一、文件整体结构

本文件为智能小船/机器人主控程序的核心，基于STM32F4系列单片机，负责各类传感器数据采集、运动控制、上位机通信、自动导航等功能。代码结构清晰，模块化程度高，便于理解和扩展。

---

## 二、主要功能模块

### 1. 头文件与模块引用
- 包含了各类传感器、控制算法、通信接口的头文件，如IMU、GPS、TDS、DS18B20、激光、超声波、滤波、PID、导航、PWM等。
- 便于后续调用各模块的初始化、数据采集、控制等函数。

### 2. 全局变量定义
- **传感器数据变量**：如`current_temperature`（温度）、`current_tds_value`（TDS）、`current_ultrasonic_distance`（超声波距离）、`current_laser_distance`（激光距离）。
- **滤波器实例**：如`ultrasonic_distance_filter`、`laser_distance_filter`，用于中值滤波。
- **控制相关变量**：如`attitude_controller`（姿态PID）、`navigation_controller`（导航）、`pwm_state`（PWM状态）、`current_pwm_mode`（当前控制模式）。
- **标志变量**：如`is_measuring_continuously`（是否连续测量）、`pid_control_enable`、`gps_navigation_enable`等。

### 3. PWM控制与安全保护
- **PWM_Safe_SetDuty**：安全设置左右电机PWM，防止突变和越界。
- **PWM_Switch_Mode**：切换手动、PID、GPS三种控制模式。
- **PWM_State_Init**：初始化PWM状态。

### 4. 主函数main()
#### 1）初始化阶段
- 初始化HAL库、系统时钟、延时、各类外设（串口、传感器、滤波器、控制器等）。
- 注册串口回调、清空数据结构体。

#### 2）主循环任务
- **命令解析**：通过UART8接收上位机命令，支持“begin”“end”“advance”“left”“right”“stop”“pid_on”“pid_off”“target_yaw:”“pid_gains:”“nav_target:”“nav_start”“nav_stop”“nav_status”等。
- **数据采集与上报**：在连续测量模式下，周期性采集TDS、温度、超声波、激光、IMU、GPS等数据，打包发送给上位机。
- **运动控制**：根据命令或自动控制算法，调整PWM，实现手动、PID、GPS导航三种运动模式。
- **安全监控**：定期检查PWM状态，异常时自动复位。

#### 3）控制算法循环
- **PID控制**：根据IMU姿态数据，自动调整航向。
- **GPS导航**：根据当前GPS坐标与目标点，自动调整航向和速度，实现自主导航。

## 三、主要命令与功能说明

| 命令            | 作用                         |
|-----------------|------------------------------|
| begin           | 开始连续测量与数据上报        |
| end             | 停止连续测量                  |
| advance         | 手动前进                      |
| left            | 手动左转                      |
| right           | 手动右转                      |
| stop            | 停止电机                      |
| pid_on          | 启用PID自动航向控制           |
| pid_off         | 关闭PID控制                   |
| target_yaw:x    | 设置目标偏航角                |
| pid_gains:a:b:c | 设置PID参数Kp:Ki:Kd           |
| nav_target:lat,lon | 设置导航目标经纬度         |
| nav_start       | 启动GPS导航                   |
| nav_stop        | 停止GPS导航                   |
| nav_status      | 查询导航状态                  |

## 四、数据上报内容

每帧数据包含：
- TDS、温度、超声波距离、激光距离
- IMU加速度、角速度、角度、磁场
- GPS时间、经纬度、状态
- PID/GPS控制状态
- 每帧以“end”结尾，便于上位机解析
